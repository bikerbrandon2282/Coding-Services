About Me

Brandon · Junior Full Stack Web Developer & Electronics Repair Technician

Who I Am

I'm Brandon, a junior full stack web developer and electronics repair technician based in Cinderford, England. I founded CodeForge Industries, where I combine software engineering with hands‑on hardware troubleshooting.

Web Development Background

I focus on building clean, accessible, and responsive web interfaces using HTML, CSS, and JavaScript. I enjoy structuring layouts with Flexbox and Grid, and I care about semantic markup and good UX. On the back‑end side, I'm learning Python and server configuration to grow into full stack roles.

  • Intermediate HTML, CSS, and modern layout techniques
  • Intermediate JavaScript for interactive front‑end behaviour
  • Beginner–intermediate server setup and configuration
  • Beginner Python for scripting and back‑end logic

Electronics & Repair Experience

I work on practical electronics repair—diagnosing faults, tracing signal paths, and restoring devices to working order. This includes TVs, game consoles, mobility scooters, and small appliances.

  • Electronics troubleshooting (beginner–intermediate)
  • Console repair (e.g., Xbox DVD laser adjustment)
  • TV mainboard and wireless hardware diagnostics
  • Battery capacity optimisation for mobility scooters

How I Work

I approach both code and hardware with an engineering mindset: understand the system, isolate the problem, and implement a clean, maintainable fix. Whether it's refactoring a layout or tracing a faulty power rail, I aim for solutions that are reliable and well‑documented.
