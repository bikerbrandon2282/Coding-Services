Services

I offer a mix of web development and electronics repair services. Below is an overview of how I can help.

Web Development Services

From simple landing pages to small web applications, I build responsive, maintainable sites tailored to your needs.

  • Custom landing pages and portfolio sites
  • Small business websites (services, contact, branding)
  • Interactive front‑end features with JavaScript
  • Bootstrap‑based responsive layouts
  • Basic back‑end integration and API consumption

Tech stack: HTML, CSS, JavaScript, Bootstrap, basic Python and server configuration.

Electronics Repair & Diagnostics

I provide practical diagnostics and repair for consumer electronics, focusing on safety and cost‑effective solutions.

  • Game console troubleshooting and repair
  • TV mainboard and wireless hardware diagnostics
  • Battery capacity optimisation for mobility scooters
  • Basic component replacement and soldering
  • General fault‑finding and power path analysis

Approach: careful inspection, methodical testing, and clear communication about repair options and risks.

Hybrid Projects & Consulting

I especially enjoy projects that combine software and hardware—like automated systems, dashboards for devices, or tools that help you manage and monitor electronics.

  • Arduino‑based automation (e.g., cocktail machine)
  • Simple web dashboards for device status or logs
  • Consulting on DIY electronics and safe design

If you have an idea that mixes code and circuits, I’d love to talk about it.
